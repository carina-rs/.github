# Carina

A strongly typed infrastructure management tool for AWS, built with Rust.

Carina treats side effects as values — resources are planned, reviewed, and then applied, giving you full control over infrastructure changes.

## Repositories

| Repository | Description |
|------------|-------------|
| [carina](https://github.com/carina-rs/carina) | Core CLI, DSL parser, LSP, and documentation site |
| [carina-provider-aws](https://github.com/carina-rs/carina-provider-aws) | AWS provider using native SDK (EC2, S3, IAM, etc.) |
| [carina-provider-awscc](https://github.com/carina-rs/carina-provider-awscc) | AWS provider using CloudControl API |
